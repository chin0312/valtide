# P1a-C versus Raw-xStock-C evaluation

`code/` contains the supplied R implementation and summary scripts. Compact results are under `../../benchmarks/p1ac_vs_rawc/` by asset. Large fold fits, cross-fit score tables, interval rows and closed-market replay rows remain in the original archives/shared storage.

The evaluation uses a chronological 80/20 split and expanding cross-fit folds. Reuse is permitted only when both asset ID and exact dataset SHA-256 match.
