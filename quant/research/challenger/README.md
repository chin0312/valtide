# Challenger-tail evidence

The detector tests whether causal P1a–xStock disagreement identifies states where raw xStock is unusually unreliable. `code/` contains the supplied script; `results/` preserves cross-asset, per-asset and event-level scored outputs.

Verdict: `RESEARCH_ONLY / REFERENCE_RELIABILITY`. The concept supports the product architecture, but fixed thresholds are asset/regime dependent and have not been confirmed on a new holdout.
